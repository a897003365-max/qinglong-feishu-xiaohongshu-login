# 飞书 · 小红书登录触发

从青龙面板“飞书-小红书登录检测”任务同步的 Python 脚本。通过飞书自建应用机器人的长连接监听群消息，在指定群中收到 `@机器人 登录` 后，先回复群消息，再发送一封主题为 `影刀-小红书登录` 的邮件，供已有的下游自动化处理。

本仓库提供飞书消息监听与邮件触发代码。二维码展示、小红书登录操作和接收邮件后的影刀流程需要另行配置。

## 安装

```sh
python -m pip install -r requirements.txt
```

依赖版本 `lark-oapi==1.7.4` 与同步时青龙运行环境一致。

## 配置

在飞书开放平台创建自建应用并启用机器人，配置长连接事件订阅 `im.message.receive_v1`，授予接收群聊中 @机器人 消息和发送消息所需权限，发布应用并将机器人加入目标群。

在本地或青龙中的 `影刀自动触发/小红书登录触发.py` 顶部填写：

| 配置 | 用途 |
| --- | --- |
| `APP_ID` | 飞书应用 ID |
| `APP_SECRET` | 飞书应用密钥 |
| `ALLOWED_CHAT_ID` | 允许触发操作的群聊 chat_id |
| `EMAIL_ADDRESS` | 发件邮箱 |
| `EMAIL_AUTH_CODE` | 邮箱 SMTP 授权码 |
| `TO_EMAIL` | 收件邮箱；留空时使用发件邮箱 |

按邮箱服务商调整 `SMTP_HOST`、`SMTP_PORT` 和 `SMTP_SECURITY`。脚本默认使用 `smtp.yeah.net:465` 和 `ssl`，也支持 `starttls`。`BOT_OPEN_ID` 会在启动时自动获取。

公开版本已清空上述六项私有配置。填写真实凭据的部署副本应单独保存，不要提交回公共仓库。脚本直接读取顶部配置，不会自动加载 `.env`。

## 运行

在仓库根目录执行：

```sh
python 影刀自动触发/小红书登录触发.py
```

青龙任务命令（脚本目录结构与本仓库一致时）：

```sh
task 影刀自动触发/小红书登录触发.py
```

这是持续监听进程。源任务使用 `@once`，运行后需要保持进程存活，避免重复启动多个实例。使用青龙订阅拉取时，请按实际脚本路径调整命令。

在允许的群聊中发送 `@机器人 登录`。机器人先回复“进入登录流程，稍后请你扫描二维码登录”，再发送邮件；其他指令回复“暂不支持该指令”。飞书回复失败时不会发邮件；同一进程内会对最近 5000 个消息 ID 去重。
